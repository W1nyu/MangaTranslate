# 개인정보 및 데이터 처리 안내

이 확장 프로그램은 사용자가 요청한 웹페이지 화면을 캡처해 같은 PC의 로컬 OCR 서버(127.0.0.1 또는 localhost)로 전송합니다. 현재 구현에서 화면 이미지는 번역 제공자에게 보내지 않습니다.

인식된 텍스트와 출발·도착 언어는 사용자가 설정한 DeepL 또는 Microsoft Azure로 전송됩니다. DeepL에는 번역 품질을 위해 같은 회차에서 직전에 인식한 말풍선 텍스트(최대 12개)도 문맥으로 함께 보냅니다. 이 문맥은 로컬 서버 메모리에만 두며 회차가 바뀌거나 서버가 종료되면 사라집니다. 해당 제공자의 데이터 처리 정책이 적용됩니다. 유료 전환은 사용자 설정이 켜져 있고 본인의 유료 키가 등록된 경우에만 사용합니다.

API 키는 로컬 서버의 `.env`에 저장되며 배포본에 포함되지 않습니다. 설정은 Chrome 동기화 저장소에, 사용자 사전은 확장 프로그램 로컬 저장소에 저장됩니다. 번역 로그와 화면 기억은 브라우저 세션 저장소를 사용합니다. 유료 사용량 집계는 PC의 `.paid-usage.json`에 기록됩니다. 원문 복사 기능은 사용자의 요청에 따라 클립보드에 텍스트를 씁니다.

개발자 운영 서버로 보내는 분석·광고 수집 기능은 없습니다. 모델·패키지 최초 설치 시, 그리고 OCR 모델(ONNX 버전 포함)을 처음 사용할 때 관련 배포 서버에 접속합니다. 공유 PC에서는 본인의 `.env`와 사전을 직접 관리하세요. 키 폐기는 해당 제공자 콘솔에서 수행할 수 있습니다.
