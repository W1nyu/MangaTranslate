다른 PC에 설치할 수 있는 Chrome/Edge 확장 프로그램 + Windows 로컬 OCR 서버 배포본입니다.

## 0.7.0 변경 사항

**OCR**
- 같은 PaddleOCR 공식 모델의 ONNX 버전을 ONNX Runtime으로 실행합니다. 만화풍 글꼴로 그린 테스트 화면(말풍선 50개)에서 인식 결과는 기존과 같았고, 페이지당 OCR 시간은 PC 부하에 따라 4~8배 줄었습니다(3.6초 → 0.44초, 5.8초 → 1.3초). ONNX 모델은 언어별로 처음 한 번 내려받으며(영어 약 13MB), 받을 수 없거나 실행에 실패하면 기존 Paddle 엔진으로 자동 전환합니다. `local-server/.env`에 `OCR_ENGINE=paddle`을 넣으면 기존 엔진을 강제합니다.
- 그림 위의 신뢰도 낮은 1~2글자 조각이 두 말풍선을 하나로 이어 붙여 둘 다 번역되지 않던 문제를 고쳤습니다. 낮은 캡처 밀도 테스트에서 말풍선 인식률 96% → 100%, 문자 오류율 4.4% → 0.07%.
- 번역 직전에 영어·라틴 문자 OCR의 글자 혼동(`G0NE` → `GONE`, `1'M` → `I'M`, `1 WON'T` → `I WON'T`)을 바로잡습니다. `LV10`, `1ST`, `10K` 같은 숫자 표기와 화면에 표시하는 OCR 원문은 바꾸지 않습니다.

**번역**
- DeepL에 같은 회차에서 직전에 읽은 말풍선(최대 12개)을 문맥으로 함께 보내, 화면이 바뀌어도 말투와 감탄사가 이어집니다(`TCH.` → `쳇.`). 문맥은 DeepL 과금 문자 수에 포함되지 않으며 로컬 서버 메모리에만 둡니다.
- 한국어로 번역할 때 DeepL에 웹툰 대사용 지침(반말 유지, 직역된 그는/그녀는 생략)을 보냅니다. 요청당 약 0.3초가 늘며 `DEEPL_WEBTOON_STYLE=0`으로 끌 수 있습니다.
- 고유명사 사전의 지정 번역을 문장 안에 고정한 채 번역해 조사까지 자연스럽게 붙습니다(`SEOUL IS UNDER ATTACK!` → `세울이 공격받고 있다!`).

**Azure Translator**
- Foundry 포털에 표시되는 `https://<리소스이름>.cognitiveservices.azure.com/` 형식의 엔드포인트를 그대로 넣어도 됩니다.
- 무료 등급(F0)의 월 200만 자를 다 쓰면 그 사실을 명확히 알리고 다른 엔진으로 넘어갑니다.

**업데이트하는 경우**: 새 폴더에 압축을 풀고 기존 `.env`를 옮긴 뒤 INSTALL.md의 설치를 다시 실행하세요. Chrome에서 새 `extension` 폴더를 다시 로드하고, 연결 확인에서 확장·서버 버전이 모두 0.7.0인지 확인하세요.

## 다운로드 및 설치

1. 아래 Assets에서 **manga-translate-0.7.0-windows.zip**을 다운로드하고 압축을 해제하세요.
2. 압축 안의 **INSTALL.md** 안내에 따라 Python 3.10/3.11 환경과 OCR 모델을 설치하세요.
3. 본인의 DeepL 또는 Azure API 키를 `local-server/.env`에 입력하세요.
4. `start-server.cmd`를 실행하고 Chrome 확장 프로그램 관리에서 개발자 모드로 `extension` 폴더를 로드하세요.

**개발자의 API 키, 개인 설정, 사용량 기록은 포함되어 있지 않습니다.** 사용자마다 본인의 키와 로컬 서버가 필요합니다. 유료 API 전환은 기본적으로 꺼져 있습니다.

- `manga-translate-0.7.0-extension.zip`: 확장 프로그램 파일만 제공. 로컬 서버가 별도로 필요합니다.
- `manga-translate-0.7.0-windows.zip`: 확장 프로그램 및 로컬 서버 소스, 설치·실행 스크립트, 설치 안내와 데이터 처리 안내.
- `SHA256SUMS.txt`: 다운로드 파일 SHA-256 검증값.

Chrome 웹 스토어 심사를 거친 등록본은 아니며 개발자 모드 수동 설치 배포입니다. 현재 작업본을 검증해 만든 ZIP을 사용하세요. GitHub가 자동 제공하는 Source code ZIP/TAR는 기준 커밋의 소스이므로 이 설치 배포본과 다릅니다.

검증: 확장 프로그램 테스트 74개, 서버 테스트 131개 통과. ZIP 허용 파일 목록·압축 무결성·로컬 API 키 혼입 검사 완료. 실제 웹툰 사이트에서의 브라우저 확인과 새 PC에서의 전체 모델 다운로드 및 설치는 별도 확인이 필요합니다.
