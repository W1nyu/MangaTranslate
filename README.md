# 말풍선 번역 레이어

웹툰 페이지의 **현재 보이는 화면**을 캡처해 OCR하고, 한국어 번역문을 원문 위에 직접 덮어 보여 주는 Chrome/Edge 확장 프로그램입니다. OCR은 내 컴퓨터에서 처리하며, 번역은 사용자가 설정한 DeepL API Free 또는 Azure Translator F0 API를 사용합니다. 무료 한도를 다 쓴 뒤에도 계속 읽고 싶다면, 직접 켠 경우에만 유료 API로 이어서 번역할 수 있습니다([3단계](#3-무료-한도가-끝났을-때-유료-api로-이어서-번역-선택)).

> 웹페이지의 이미지·canvas·cross-origin iframe 안 텍스트는 일반 웹앱이 읽을 수 없습니다. 그래서 이 프로젝트는 웹툰 페이지 위에 작동하는 브라우저 확장 프로그램으로 만들었습니다.

## 구성

```text
웹툰 페이지
  └─ Chrome/Edge 확장 프로그램
       ├─ 현재 보이는 탭 캡처
       ├─ 원문 위 번역 패치 표시
       └─ 설정·고유명사 사전
              │ localhost only
              ▼
     로컬 모델 서버 (FastAPI)
       ├─ PaddleOCR (무료 OCR)
       └─ 번역 엔진 선택
            ├─ DeepL API Free (우선 · OCR 텍스트만 전송)
            ├─ Azure Translator F0 (백업 · OCR 텍스트만 전송)
            └─ 무료 한도 소진 시에만 (사용자가 켠 경우)
                 ├─ DeepL API Pro (유료)
                 └─ Azure Translator 유료 등급
```

- **OCR로 추출한 텍스트와 언어 코드만** DeepL 또는 Azure로 전송되며, 화면 이미지 자체는 로컬 서버 밖으로 나가지 않습니다.
- 확장 프로그램은 사용자가 **화면 번역 시작**을 누른 현재 탭에만 레이어를 삽입하며, 페이지를 이동하면 접근 권한도 해제됩니다.
- `SEOUL → 세울`처럼 고유명사 사전을 등록하면 기계 번역보다 우선 적용됩니다.
- 출발/도착 언어, 자동 재인식, 오버레이 불투명도와 글자 크기를 바꿀 수 있습니다.
- 가까운 영어 OCR 줄은 하나의 말풍선으로 묶어 한 문장으로 번역합니다. `원문` 버튼을 누르면 번역 패치를 숨겨 실제 원문을 다시 볼 수 있습니다.
- 화면 번역을 한 뒤 팝업의 **현재 화면 원문 복사** 또는 우측 상단 레이어의 **복사**를 누르면, 현재 화면에서 OCR한 원문을 읽기 순서대로 클립보드에 복사할 수 있습니다.
- 현재 화면이 바뀌거나 스크롤이 멈춘 뒤 다시 인식합니다. Chrome의 화면 캡처 제한 때문에 동영상 같은 매 프레임 번역은 하지 않습니다.
- 스크롤하는 동안에는 이미 인식한 번역 패치가 원래 말풍선의 문서 위치를 따라 함께 이동합니다. 말풍선이 화면 밖으로 완전히 나가면 해당 번역은 숨기고, 새 화면의 OCR 결과가 도착하면 그 결과로 교체합니다.
- 위아래로 돌아와 **같은 화면**을 다시 볼 때는 확장 프로그램이 직전 결과를 즉시 복원해 OCR과 서버 요청을 생략합니다. 화면 위치가 조금 달라도 회차 안에서 같은 OCR 원문은 서버 캐시를 재사용하므로 Azure·DeepL 번역 한도를 다시 쓰지 않습니다.
- 이 기억은 현재 회차 URL(`origin + pathname + search`) 안에서만 유지되며, 다음 회차로 이동하면 자동으로 비워집니다. 확장 프로그램을 새로고침한 뒤에는 Chrome 정책상 기존 웹툰 탭도 새로고침해야 합니다.
- 팝업의 **이번 회차 번역 로그**에서 OCR 원문과 번역문, 시간, 언어쌍, 사용한 번역 엔진을 확인할 수 있습니다. 같은 원문·번역문은 한 번만 기록하며, 전체 복사와 수동 비우기도 지원합니다.
- OCR 결과는 선택한 출발 언어와 일치한다고 판별된 영역만 번역합니다. 한글·일본어·중국어·키릴 문자처럼 명확히 다른 문자권은 제외하고, 라틴 문자 언어끼리는 강한 언어 단서가 있을 때만 다른 언어로 판정해 정상적인 짧은 대사가 사라지는 일을 줄입니다.
- **화면 번역 시작**을 누르면 먼저 번역 영역 선택 화면이 열립니다. 범위를 드래그하거나 **전체 화면**을 명시적으로 선택하기 전에는 OCR을 시작하지 않습니다. 한 번 고른 범위는 이후 스크롤·자동 재인식에 계속 적용되며, 레이어의 **영역** 버튼에서 필요할 때만 다시 지정할 수 있습니다. 이 범위는 현재 탭·페이지 세션에만 유지되며, 페이지 이동 또는 새로고침 시 자동 해제됩니다.

## 빠른 시작

### 1. 첫 실행: 설치와 모델 준비

최초 한 번만 가상환경, 무료 OCR·번역 패키지, 선택한 언어 모델을 설치합니다. Python 3.10–3.13을 사용하세요. 이 PC의 기본 `python`은 3.14이므로 아래 Python 3.10 경로를 명시합니다.

```powershell
cd C:\Users\Winyu\Documents\Project\manga\local-server
.\scripts\bootstrap.ps1 -PythonPath 'C:\Users\Winyu\AppData\Local\Programs\Python\Python310\python.exe' -SourceLanguage en -TargetLanguage ko
```

설치가 끝나면 같은 PowerShell 창에서 서버를 시작합니다.

```powershell
.\.venv\Scripts\python.exe .\scripts\run_server.py
```

`Uvicorn running on http://127.0.0.1:8765`가 표시되면 준비된 것입니다. 처음 확장 프로그램에서 **화면 번역 시작**을 누를 때 PaddleOCR 모바일 모델도 한 번 내려받아 초기화됩니다. 이 서버 창은 번역하는 동안 열어 두세요.

직접 언어쌍이 없으면 설치 스크립트가 가능한 가장 짧은 중간 언어 경로(예: 일본어 → 영어 → 한국어)를 함께 설치합니다. 새 언어쌍을 추가할 때만 아래처럼 실행합니다.

```powershell
.\.venv\Scripts\python.exe .\scripts\install_models.py --from ja --to ko
.\.venv\Scripts\python.exe .\scripts\smoke_test.py --from ja --to ko --text "こんにちは"
```

### 2. Azure + DeepL 무료 API 설정 (권장)

두 서비스를 모두 등록해 두면 확장 프로그램에서 엔진을 직접 고르거나, **자동** 모드로 DeepL → Azure 순서로 사용할 수 있습니다. 한 서비스의 무료 한도·인증·네트워크 오류가 나면 자동 모드는 다음 클라우드 엔진을 시도합니다. Azure 또는 DeepL을 직접 고른 경우에도 실패하면 다른 클라우드 엔진만 백업으로 사용하며, 로컬 Argos 번역으로는 전환하지 않습니다.

키는 확장 프로그램에 넣지 않고 `local-server/.env`에만 보관합니다. 이 파일은 Git에서 제외되어 있으며 서버를 시작할 때 자동으로 읽습니다.

```powershell
cd C:\Users\Winyu\Documents\Project\manga\local-server
Copy-Item .env.example .env
notepad .env
```

열린 `.env`에 아래 두 서비스의 값을 채운 뒤 저장하세요.

1. **Azure Translator F0** — Azure Portal에서 Translator 리소스를 만들고, 리소스의 **Keys and Endpoint** 화면에서 키와 리전을 복사합니다. `AZURE_TRANSLATOR_KEY`, `AZURE_TRANSLATOR_REGION`에 넣고, 별도 엔드포인트가 표시된 경우에만 `AZURE_TRANSLATOR_ENDPOINT`를 바꿉니다. [Azure Translator 빠른 시작](https://learn.microsoft.com/azure/ai-services/translator/text-translation/quickstart/rest-api)
2. **DeepL API Free** — DeepL API Free 계정의 **API Keys** 화면에서 인증 키를 복사해 `DEEPL_AUTH_KEY`에 넣습니다. Free 키는 보통 `:fx`로 끝나며, `DEEPL_API_ENDPOINT`는 Free 전용 주소로 그대로 둡니다. [DeepL API 키 안내](https://developers.deepl.com/docs/getting-started/auth)

예시는 다음과 같습니다. 실제 키는 절대로 README, 확장 프로그램 설정, 스크린샷이나 채팅에 붙여 넣지 마세요.

```dotenv
AZURE_TRANSLATOR_KEY=여기에_Azure_키
AZURE_TRANSLATOR_REGION=리소스_리전
DEEPL_AUTH_KEY=여기에_DeepL_키
```

서비스를 하나만 설정해도 됩니다. 비워 둔 서비스는 선택 목록에서 사용할 수 없거나 자동 모드에서 건너뜁니다. `.env`를 수정한 뒤에는 실행 중인 서버를 `Ctrl+C`로 종료하고 다시 시작해야 새 키가 적용됩니다.

### 3. 무료 한도가 끝났을 때 유료 API로 이어서 번역 (선택)

무료 등급은 스스로 멈춥니다. DeepL Free는 월 한도를 넘기면 456을, Azure F0는 403을 돌려주고, 그 시점부터 화면 번역이 그냥 중단됩니다. 유료 키를 넣어 두면 **그때만** 유료 API로 이어서 번역할 수 있습니다.

이 기능은 **기본적으로 꺼져 있습니다.** 켜기 전까지는 유료 키가 `.env`에 있어도 절대 호출하지 않습니다.

**1) `.env`에 유료 키를 넣습니다.** 둘 중 하나만 넣어도 됩니다.

```dotenv
# DeepL API Pro — Free 키와 다른 키이며 호스트도 다릅니다.
# Free 키(:fx로 끝나는 키)를 여기에 넣으면 "설정 안 됨"으로 처리합니다.
DEEPL_PRO_AUTH_KEY=
DEEPL_PRO_API_ENDPOINT=https://api.deepl.com/v2

# Azure Translator 유료 등급(S1 이상). 별도 리소스를 쓰거나 F0 리소스를 승급하세요.
AZURE_TRANSLATOR_PAID_KEY=
AZURE_TRANSLATOR_PAID_REGION=

# 이번 달에 유료 엔진으로 번역할 수 있는 최대 문자 수입니다.
# 이 수를 넘으면 서버가 유료 호출을 거절합니다. 0으로 두면 상한이 없어집니다.
PAID_MONTHLY_CHAR_LIMIT=500000
```

**2) 서버를 다시 시작한 뒤**, 확장 프로그램의 **고유명사 사전 · 세부 설정**을 열고 **무료 한도가 끝나면 유료 API로 계속 번역**을 체크하고 **설정 저장**을 누릅니다.

동작 방식은 다음과 같습니다.

- 유료 엔진은 **무료 엔진을 모두 실제로 시도해 실패한 뒤에만** 사용합니다. 무료 한도가 남아 있으면 유료 키가 있어도 호출하지 않습니다.
- 선택한 엔진의 성격을 유지합니다. `DeepL`을 골랐다면 DeepL API Pro로, `Azure`를 골랐다면 유료 Azure Translator로 이어집니다.
- 유료 엔진으로 번역한 화면은 오른쪽 위 레이어 상태줄에 `유료 사용 중`으로 표시되고, 팝업 안내문에도 유료 사용 중임이 나옵니다.
- 서버는 유료 엔진에 보낸 문자 수를 `local-server/.paid-usage.json`에 달 단위로 기록합니다. 서버를 껐다 켜도 사용량은 초기화되지 않으며, 달이 바뀌면 자동으로 0부터 다시 셉니다. 이 파일은 Git에서 제외되어 있습니다.
- 상한에 도달하면 유료 호출을 멈추고, 남은 한도는 설정 화면과 팝업에서 확인할 수 있습니다.
- 화면 캐시와 중복 말풍선 제거가 먼저 적용된 **실제로 전송한 문자 수**만 집계합니다. 같은 구간을 다시 읽어도 유료 사용량이 늘지 않습니다.

체크박스를 다시 끄면 그 즉시 유료 호출을 하지 않으며, 무료 한도가 끝난 상태에서는 번역이 멈춥니다.

### 5. 서비스 종료 방법

일반적으로 위 PowerShell 창에서 실행했다면 `Ctrl+C`를 한 번 눌러 종료하세요. `Application shutdown complete.`가 보이면 안전하게 끝난 것입니다.

현재처럼 백그라운드 작업으로 실행했다면 아래 명령으로 종료할 수 있습니다.

```powershell
schtasks /End /TN MangaTranslatorLocalServer
```

서버를 끈 동안에는 확장 프로그램의 화면 번역 요청이 동작하지 않습니다.

### 6. 확장 프로그램 설치

1. Chrome 또는 Edge에서 `chrome://extensions`를 엽니다.
2. **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
4. 이 저장소의 [`extension`](extension) 폴더를 선택합니다.
5. 웹툰 페이지를 열고 확장 아이콘에서 출발/도착 언어와 **번역 엔진**을 선택한 뒤 **화면 번역 시작**을 누릅니다. 두 무료 API를 설정했다면 `자동 (DeepL → Azure)`를 선택하세요.
6. 화면에서 번역할 영역을 드래그하거나 **전체 화면**을 누르면 바로 번역이 시작됩니다.

## 읽는 동안의 동작

스크롤을 **멈춘 뒤 약 0.5초** 뒤에 인식이 시작됩니다. 계속 내리는 중에는 캡처하지 않으므로, 빠르게 지나가는 화면 때문에 번역이 깜빡이지 않습니다. 대기 시간은 옵션에서 바꿀 수 있습니다.

말풍선이 **전부 보일 때만** 번역합니다.

- 화면 가장자리에 반쯤 걸친 말풍선은 건너뜁니다. 반쪽짜리 문장을 읽으면 그럴듯하지만 틀린 번역이 나오기 때문입니다. 조금 더 스크롤해서 말풍선 전체가 보이면 그때 번역합니다.
- 말풍선 없이 그림 위에 그려진 글자(효과음, 간판 등)는 번역하지 않습니다. 말풍선이 없는 자리에 번역 패치가 떠 있지 않게 하기 위해서입니다.
- 판정은 캡처한 픽셀로 합니다. 말풍선은 밝은 배경이므로, 그 밝은 영역이 화면 밖으로 이어지면 잘린 것으로 봅니다.
- 이 동작이 너무 엄격하게 느껴지면 옵션의 **말풍선이 다 보일 때만 번역**을 끄면 됩니다.

번역은 **말풍선 단위로 기억**됩니다.

- 스크롤해서 말풍선이 화면 밖으로 나가면 그 번역도 함께 사라집니다.
- 같은 자리를 다시 읽었는데 말풍선이 계속 없으면, 그 번역 패치는 정리됩니다.
- 새로 나타난 말풍선만 인식합니다. 화면 전체가 아니라 **새로 드러난 부분만** 캡처하므로 OCR 시간이 그만큼 줄어듭니다.
- 이미 읽은 구간으로 되돌아가면 서버를 다시 부르지 않고 **기억해 둔 번역을 즉시** 표시합니다.
- **원문** 버튼으로 번역을 숨긴 상태에서도, 말풍선 위에 마우스를 올리면 그 말풍선의 번역만 다시 나타납니다. (옵션에서 끌 수 있습니다.)
- 번역은 그림(`<img>`) 기준으로 고정되므로, 지연 로딩으로 페이지가 밀려도 말풍선을 따라갑니다.

기억한 번역은 **탭 세션**에만 남습니다. 탭을 닫으면 사라지고 디스크에는 기록되지 않습니다. 다른 회차로 이동하면 이전 회차의 번역은 함께 버려집니다.

툴바의 상태 문구에 마우스를 올리면 이번 스캔이 화면 전체를 읽었는지 새로 나온 부분만 읽었는지와, 캡처·왕복·OCR·번역에 각각 걸린 시간이 표시됩니다. 느리다고 느껴질 때 어디가 병목인지 바로 확인할 수 있습니다.

## 고유명사 사전 사용법

확장 프로그램의 **고유명사 사전**에서 아래처럼 등록하세요.

| 원문 | 지정 번역 | 출발 → 도착 | 대소문자 구분 |
| --- | --- | --- | --- |
| `SEOUL` | `세울` | 영어 → 한국어 | 켬 |

이 규칙이 있으면 `SEOUL`은 일반 번역 결과인 `서울`이 아니라 항상 `세울`로 표시됩니다. 같은 단어의 OCR 오인식이 잦으면 별칭을 별도 항목으로 추가할 수 있습니다.

## 지원 언어와 품질

UI에는 영어, 한국어, 일본어, 중국어(간체), 스페인어, 프랑스어, 독일어, 포르투갈어, 러시아어, 베트남어를 넣었습니다. Azure·DeepL의 실제 지원 언어와 무료 한도, 유료 요금은 각 계정의 서비스 정책을 따릅니다. 이 확장 프로그램의 월 문자 상한은 과금을 대신 관리해 주는 장치가 아니라 실수로 크게 쓰는 일을 막기 위한 보호선이므로, 실제 청구 금액은 각 서비스 콘솔에서 직접 확인하세요.

만화체, 세로쓰기, 효과음, 그림 위의 작은 글씨는 OCR 오류가 날 수 있습니다. 이 버전은 원문을 완벽히 지우고 말풍선을 복원하는 도구가 아니라, OCR된 말풍선 영역 위에 읽기 쉬운 번역 패치를 올리는 실용적인 MVP입니다.

## 개발 및 검증

로컬 서버 단위 테스트:

```powershell
cd local-server
python -m unittest discover -s tests -v
```

확장 프로그램의 좌표·병합·증분 캡처 계산은 Node로 검증합니다 (설치할 의존성은 없습니다):

```powershell
node --test "extension/tests/**/*.test.mjs"
```

브라우저 자바스크립트는 별도의 번들러 없이 작성했습니다. 변경 후 `chrome://extensions`에서 이 확장 프로그램의 새로고침 버튼을 누른 뒤 웹툰 탭도 새로고침하세요.
